# WorkPulse 0.1.1

## Download

- `WorkPulse-0.1.1-macos.dmg`

## Install

Download the DMG, open it, and drag `WorkPulse.app` to `Applications`.

## Notes

- Local-first daily work tracking.
- Project color coding and progress tracking.
- Calendar boards for week, month, and year views.
- Review summaries with optional OpenAI-compatible AI support.
- API keys are stored in macOS Keychain.
- Keychain reads were reduced: normal status display checks only whether a key exists; the key value is read only when needed for testing or AI review generation.

This build is not notarized. macOS may ask for confirmation on first launch.
